מאגר המקור של **מסע הניקוד**.

## מצב מאושר
- הלוחות המעוצבים הם הלוח עצמו; אין לצייר שכבת לוח נוספת מעליהם.
- ה-hotspots של המשבצות שקופים לחלוטין וממופים ללוח הקיים.
- בבחירת לוח ובמשחק נעשה שימוש באותו עיצוב מאושר.
- קיים fallback לתמונת התצוגה במקרה ש-texture הלוח הראשי אינו נטען.
- המשחק נבדק אצל המשתמש ועובד, כולל יצירת Windows EXE.
