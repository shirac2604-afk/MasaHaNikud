# מסע לניקוד

גרסה מאושרת: **v1.0.3**

משחק שולחן לימודי לתרגול ניקוד עברי.

## סטטוס
הגרסה נבדקה אצל המשתמש ואושרה כגרסת העבודה האחרונה. עקרון העיצוב המאושר נשמר: תמונת הלוח היא הלוח עצמו, וה־hotspots האינטראקטיביים שקופים לחלוטין.

## תיקון מרכזי ב־v1.0.3
- תוקנה התקלה שבה הלוח לא הופיע לאחר מעבר ל־Hotspots שקופים.
- המשחק משתמש בקובצי הלוח המלאים מתוך `assets/boards/approved`.
- אין שכבת מסלול או משבצות נוספת מעל האיור.
- נוסף fallback לתמונת התצוגה אם texture של הלוח אינו נטען.

## פיתוח והרצה
```bash
npm install
npm run dev
```

בדיקות זמינות בפרויקט דרך סקריפטי `npm run qa` ו־`npm run check`.

## גיבוי מקור
חבילת המקור המלאה של הגרסה המאושרת נשמרת במאגר לצורך שחזור והמשך עבודה.
